🎯 The five rules that decide this paper

  • Do NOT optimise. At 15 min/problem, an O(n²) solution that passes is worth exactly the same as an elegant O(n). Write the obvious thing, submit, move on. Optimise only with leftover time.
  • Read all three first, solve easiest first. Every problem is worth the same. Burning 25 min on the hardest and leaving two untouched is the single most common way to fail this format.
  • Type the I/O boilerplate before you think. Function signature, return statement, print — get the skeleton down, then fill the logic. Blank-editor paralysis is the killer.
  • Test on the sample input only. No custom test cases unless something fails. You don't have the time.
  • Never leave an empty editor. Partial test-case credit is real. Even a loop that handles the simple case scores above zero.

🐍 Python idioms that buy you minutes

Memorise the shape, not the theory. Every line here replaces 4–6 lines of manual loop — that's the difference between three submitted problems and two.

Strings

s[::-1]                      # reverse a string
s == s[::-1]                 # palindrome check
s.lower(), s.upper()         # case normalise before comparing
sorted(a) == sorted(b)       # anagram check (good enough at this tier)
s.replace(" ", "")           # strip spaces
sum(1 for c in s if c in 'aeiou')      # vowel count
''.join(c for c in s if c.isalnum())   # keep letters+digits only
s.split()                    # words list

Counting / frequency — the single biggest time-saver

from collections import Counter
c = Counter(arr)             # {value: count} in ONE line
c.most_common(1)[0][0]       # most frequent element
c.most_common()              # all, sorted by count desc
[k for k,v in c.items() if v == 1]     # elements appearing once

# first non-repeating character
for ch in s:
    if c[ch] == 1:
        return ch

Arrays

max(arr), min(arr), sum(arr)
sum(arr)/len(arr)            # average
sorted(arr)[-2]              # second largest (careful with duplicates)
sorted(set(arr))[-2]         # second largest, distinct
list(set(arr))               # remove duplicates (loses order)
arr[::-1]                    # reverse
arr.count(x)                 # occurrences of x
len(arr) != len(set(arr))    # has duplicates?
[x for x in arr if x != 0]   # filter
n*(n+1)//2 - sum(arr)        # missing number from 1..n

Math

str(n)[::-1]                 # reverse a number (via string)
sum(int(d) for d in str(n))  # digit sum
n % 2 == 0                   # even
divmod(a, b)                 # (quotient, remainder)
import math
math.gcd(a, b)               # GCD built in
a*b // math.gcd(a,b)         # LCM
math.sqrt(n), math.isqrt(n)  # isqrt = integer sqrt, no float error

def is_prime(n):             # memorise this shape
    if n < 2: return False
    for i in range(2, int(n**0.5)+1):
        if n % i == 0: return False
    return True

S1 · STRINGS
Reverse a string without using built-in reverse. 
def rev(s):
    out = ""
    for ch in s:
        out = ch + out      # prepend each char
    return out

# l, r = 0, len(a)-1

S2 · STRINGS
Check if a string is a palindrome, ignoring case and non-alphanumeric characters. ("A man, a plan, a canal: Panama" → true) 
def is_pal(s):
    t = ''.join(c.lower() for c in s if c.isalnum())
    return t == t[::-1]
S3 · STRINGS
First non-repeating character in a string (return it, or '_' if none). 
from collections import Counter
def first_uniq(s):
    c = Counter(s)
    for ch in s:            # iterate the STRING, not the counter
        if c[ch] == 1:
            return ch
    return '_'

Trap: iterating c instead of s loses original order in older Python semantics — always loop the string.

S4 · STRINGS
Count vowels and consonants in a string. 
def count(s):
    v = sum(1 for c in s.lower() if c in 'aeiou')
    cons = sum(1 for c in s.lower() if c.isalpha() and c not in 'aeiou')
    return v, cons
S5 · STRINGS
Reverse the order of words in a sentence. ("the sky is blue" → "blue is sky the") 
def rev_words(s):
    return ' '.join(s.split()[::-1])
# .split() with no args collapses multiple spaces for free
A1 · ARRAYS
Second largest element in an array (handle duplicates). 
def second_largest(arr):
    u = sorted(set(arr))
    return u[-2] if len(u) >= 2 else None

Trap: sorted(arr)[-2] returns the same value again for [5,5,3]. Dedupe first.

A2 · ARRAYS
Find the missing number from an array containing 1..n with exactly one missing. 
def missing(arr, n):
    return n*(n+1)//2 - sum(arr)
# O(n) time, O(1) space, no sorting needed
A3 · ARRAYS
Move all zeroes to the end, keeping the order of non-zero elements. 
def move_zeroes(arr):
    pos = 0                       # writer pointer
    for x in arr:
        if x != 0:
            arr[pos] = x; pos += 1
    while pos < len(arr):
        arr[pos] = 0; pos += 1
    return arr
A4 · ARRAYS
Remove duplicates from a sorted array in place, return the new length. 
def dedupe(arr):
    if not arr: return 0
    w = 1                         # writer pointer
    for i in range(1, len(arr)):
        if arr[i] != arr[i-1]:
            arr[w] = arr[i]; w += 1
    return w
A5 · ARRAYS
Most frequent element in an array. 
from collections import Counter
def most_frequent(arr):
    return Counter(arr).most_common(1)[0][0]
M1 · MATH
Check if a number is prime. 
def is_prime(n):
    if n < 2: return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0: return False
    return True

Trap: forgetting n < 2 (1 and 0 are not prime), or looping to n instead of √n.

M2 · MATH
Reverse an integer (123 → 321, handle negatives). 
def rev_num(n):
    sign = -1 if n < 0 else 1
    return sign * int(str(abs(n))[::-1])
M3 · MATH
Print the first n Fibonacci numbers. 
def fib(n):
    a, b, out = 0, 1, []
    for _ in range(n):
        out.append(a)
        a, b = b, a + b     # simultaneous assignment, no temp var
    return out
M4 · MATH
Armstrong number check (153 = 1³+5³+3³). 
def is_armstrong(n):
    d = str(n); p = len(d)
    return n == sum(int(c)**p for c in d)
M5 · MATH
GCD and LCM of two numbers. 
import math
def gcd_lcm(a, b):
    g = math.gcd(a, b)
    return g, a * b // g

Gotchas that eat Java minutes

  • == compares references for Strings — always use .equals()
  • int/int truncates: 7/2 = 3. Cast for a real average: (double) sum / n
  • Arrays are fixed length. Need to grow? ArrayList<Integer>
  • arr.length (no parens) but s.length() (with parens) — the classic 30-second bug
  • Mixing nextInt() and nextLine() leaves a dangling newline — add an extra sc.nextLine() after the int read
